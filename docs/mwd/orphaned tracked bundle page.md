^ orphaned [[bundle page tracking state -- tracked]]

---

You can have a [[bundle page]] that was in [[bundle page tracking state -- tracked]], but then, because of a [[source graph change]], when you go back to the bundle in [[bundle lifecycle -- ongoing updates]], the link to it can be removed, so It is no longer pointed to by any [[bundle page path]].  So, it is orphaned.

Ultimately we will need to deal with that in [[orphaned tracked bundle page resolution tooling]]
