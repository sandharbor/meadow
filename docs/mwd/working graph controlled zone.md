Roughly the zone dictated by [[bundle page config -- outlinksDepth]] and [[bundle page config -- inlinksDepth]] constraints. Essentially all the connected bundle pages within the [[raw working graph]], excluding any [[frontier bundle page]]s, if we happen to be showing them.

This idea does not care about the [[bundle page tracking state]] for the [[bundle page]]s in it.  In other words, untracked pages can be part of the controlled zone.  Also, a [[blacklisted bundle page]] is part of the [[working graph controlled zone]].

]It doesn't include frontier bundle pages because [[frontier bundle pages cannot be tracked]].
