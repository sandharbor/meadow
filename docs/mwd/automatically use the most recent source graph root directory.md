If you are not using the [[Meadow Obsidian plugin]], then when you [[create a new bundle from a source page]], you need to supply both the [[bundle page type -- initial]] and the [[source graph root directory]].

That's a bit of a pain, but it is necessary when you are [[doing things the first time]].

But from the second time onwards we can provide an [[affordance]] where we automatically use the [[source graph root directory]] from the bundle the user created most recently. The source directory generated for the built-in example bundle is excluded from both this default and the list of reusable directories; choosing the example flow is the explicit way to use that content.

We do this to help with [[design motivation -- speed]], and with [[design motivation -- easy setup]], since it means that someone can use the app pretty effectively without needing to install the [[Meadow Obsidian plugin]]
