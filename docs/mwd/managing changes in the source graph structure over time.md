Managing [[source graph change]]

Unlike standard [[publishing modality -- blog]], the [[publishing modality -- meadow bundle]]s are backed by [[source graph]]s that change over time.  Part of our [[meadow change management]] challenge is related to dealing with these [[source graph]] structural changes.

When the source graph changes you can end up with [[orphaned tracked bundle page]]s, or a bunch of newly [[bundle page tracking state -- untracked]] pages within the [[working graph controlled zone]].

This can be especially problematic at scale, and needs to be addressed by [[multi bundle management]].  But you don't necessarily care about all of your bundles equally.  Maybe you make some bundles as one-offs, which is why we've added [[bundle state -- archived]] as a type (shunted off into another tab).
