Take a [[raw working graph]] and set [[bundle page tracking state -- tracked]] on some (or all) of the bundle pages.  The tracked working graph is those pages.

The [[final working graph]] is only the [[whitelist]]ed [[bundle page]]s in the tracked working graph.

The tracked working graph does not contain [[frontier bundle page]]s because [[frontier bundle pages cannot be tracked]]

The tracked working graph is not necessarily a [[fully connected graph]]. It can have an [[inconsistent state -- untracked bundle page within controlled zone]], which we warn people about.
