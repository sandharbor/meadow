This is a special mode where you provide a [[source page]] , either by using the [[Meadow Obsidian plugin]] or by clicking the "find in bundles" action in the [[app component -- bundle page card]] dropdown

It opens the [[app page -- bundles list]] and shows all the [[bundle]]s containing the page.

It also allows allows you to easily [[create a new bundle from a source page]]

Related to [[multi bundle management]].
