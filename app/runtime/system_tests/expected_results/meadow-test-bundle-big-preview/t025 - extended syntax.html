t025 - extended syntax

This page is a comprehensive enumeration of every extended markdown syntax variation from https://www.markdownguide.org/extended-syntax/. Some features (tables, fenced code blocks) are duplicated in other tests; this page is the single source of truth for the complete extended-syntax set.

This page starts with frontmatter that ends with a ... line instead of ---, which YAML also allows. Like any frontmatter, it should not appear anywhere on the rendered page.

Callout Type Containing Quotes

The odd-looking callout below is deliberate. Its type, between [! and ], is the text note" data-injected="yes. The type is copied into the callout's HTML class attribute, so if its quotes were not escaped they would close that attribute early and add a separate data-injected="yes" attribute to the page. That is how a note could inject HTML.

Rendered correctly, the callout below has no data-injected attribute. Its title shows the type exactly as written, because a callout without a title shows its type, and it uses the default callout style, because the type is not one of the known callout types.

Note" data-injected="yes

Yes, this title is meant to look strange: it is the type text, shown as plain text. See the explanation above.

Comments

There is a comment below this line that you will not see in the rendered output.

And here is a block comment that spans multiple lines:

Text continues after the comment.

Comments inside code blocks should be preserved: 

%%This should not be stripped%%

Inline code too: %%also preserved%%

Two percent signs written with a backslash are text, not a comment: %%this stays visible%%

A comment can contain a link. As in Obsidian, the link still counts, so the linked page lists this page among its backlinks, but the comment's text must not appear here or in that page's backlinks.

Escaping

A backslash before a character shows that character instead of its Markdown meaning. None of these should become a link, a tag, math, or formatting:

  • Not a link: [[main page]]
  • Not an embed: ![[main page]]
  • Not a tag: #t025-not-a-tag
  • Not math: $5 and $10
  • Not italic: *not italic*
  • Not a table separator: a | b

Unclosed Comment

A comment that is never closed hides the rest of the note, as in Obsidian. The line after this one opens such a comment, so nothing after it should appear on the page.
