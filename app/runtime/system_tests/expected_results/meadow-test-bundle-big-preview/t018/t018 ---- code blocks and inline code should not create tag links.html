t018 ---- code blocks and inline code should not create tag links

This page should NOT create tag links from code blocks or inline code, or from other # characters that are not tags.

Inline code: #tag-inside-code-ticks 

#tag-inside-fenced-code-block
some other text

Each of the next three lines contains a # that belongs to something else, not to a tag. None of them should become a tag link, and the two links should keep working.

A Markdown link to a heading on this page: the heading

An HTML link to the top of the page: top

An HTML entity for an apostrophe: it's
