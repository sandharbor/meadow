# Markdown spec examples

Test data for `markdownSpec.test.ts`, unchanged from their sources:

- `commonmark-0.31.2-spec.json`: the examples of the CommonMark Spec 0.31.2,
  from <https://spec.commonmark.org/0.31.2/spec.json>.
- `gfm-spec.txt`: the GitHub Flavored Markdown Spec 0.29, from
  <https://github.com/github/cmark-gfm/blob/master/test/spec.txt>.
